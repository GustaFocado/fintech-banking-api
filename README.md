# Fintech Banking API

Projeto de uma aplicação bancária desenvolvido de forma incremental para praticar Java Backend.

## Objetivo

Construir uma API bancária começando pela modelagem em Java puro e evoluindo para Spring Boot, banco de dados, testes e outras tecnologias do ecossistema backend.

## Funcionalidades planejadas

- Cadastro de clientes
- Criação de contas
- Depósitos
- Saques
- Transferências
- Histórico de transações

## Tecnologias

- Java

## Status

Em desenvolvimento.
